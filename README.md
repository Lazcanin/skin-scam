# Skin Scam

Prototipo interactivo de **Skin Scam**, una app de análisis de skincare que escanea ingredientes (INCI) de cosméticos.

## Ver el prototipo

Abrir en el navegador (recomendado en celular):

**[Ver Demo en Vivo](https://USUARIO.github.io/skin-scam/)**

> Reemplazar `USUARIO` con el nombre de usuario de GitHub después del deploy.

## Pantallas

| Pantalla | Descripción |
|---|---|
| **Onboarding** | Bienvenida con logo y botón de inicio |
| **Home** | Dashboard con perfil de piel, escaneo rápido y rutina del día |
| **Scanner** | Cámara simulada con análisis de ingredientes tipo semáforo |
| **Community** | Feed de reseñas filtradas por "Skin Twins" (mismo tipo de piel) |
| **Routine** | Organizador de rutina AM/PM con tips de compatibilidad |
| **Profile** | Perfil del usuario con estadísticas |

## Navegación

Los botones del menú inferior navegan entre pantallas. El botón central rosa abre el escáner. Todos los elementos son interactivos (filtros, likes, toggles) pero sin funcionalidad real — es un prototipo visual.

## Tecnologías
- HTML5
- CSS3 (Vanilla, sin framework)
- JavaScript vanilla
- Google Fonts (Poppins + DM Sans)
- Bootstrap Icons
